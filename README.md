# GammaEdge

**GammaEdge** is a clean, modern **options trading simulator** focused on weekly options and intraday practice. It provides a realistic trading experience without the clutter of traditional brokers. Users can view charts, select weekly contracts, place simulated trades, and track PnL in real time — all with virtual money.

---

## Features

- Live-like stock price updates
- Weekly option chains for liquid tickers
- Buy calls or puts with market or limit orders
- Set profit targets and stop losses
- Realistic bid/ask spreads and option behavior
- Automatic tracking of entries, exits, and PnL
- Simple, intuitive UI built for active traders

---

## Goal

The goal of GammaEdge is to help traders develop confidence, discipline, and skill in options trading by giving them a realistic environment to practice. By focusing on weekly expirations, live-like market behavior, and intuitive controls, GammaEdge allows users to experience how options truly move — letting them learn strategies, refine timing, and improve decision-making without risking real capital.
