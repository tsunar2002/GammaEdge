# GammaEdge

**GammaEdge** is a clean, modern **options trading simulator** focused on weekly options and intraday practice. It provides a realistic trading experience without the clutter of traditional brokers. Users can view charts, select weekly contracts, place simulated trades, and track PnL in real time — all with virtual money.

> **Note:** This application uses **historical market data** to simulate trading environments. It does **not** provide real-time live market data.

---

## Features

- **Simulated Market Data**: Experience live-like price action using historical data replays.
- **Weekly Option Chains**: Practice with realistic option chains for liquid tickers.
- **Order Types**: Buy calls or puts with market or limit orders.
- **Risk Management**: Set profit targets and stop losses.
- **Realistic Simulation**: Mimics bid/ask spreads and option pricing behavior.
- **Performance Tracking**: Automatic tracking of entries, exits, and PnL.
- **Modern UI**: Simple, intuitive interface built for active traders.

---

## Goal

The goal of GammaEdge is to help traders develop confidence, discipline, and skill in options trading by giving them a realistic environment to practice. By focusing on weekly expirations, simulated market behavior, and intuitive controls, GammaEdge allows users to experience how options truly move — letting them learn strategies, refine timing, and improve decision-making without risking real capital.
